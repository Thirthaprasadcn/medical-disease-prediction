# Local sample datasets (50 each)

| Folder | PPT dataset | Purpose | Count |
|--------|-------------|---------|-------|
| `01_chest_xray_pneumoniamnist` | PneumoniaMNIST | Pneumonia vs Normal | 50 |
| `02_brain_mri_tumor` | Brain Tumor MRI dataset | 4-class tumor classification | 50 |
| `03_chest_ct_lidc_style` | LIDC-IDRI (proxy: NoduleMNIST3D) | Lung nodule detection | 50 |
| `04_brain_mri_segmentation_brats_style` | BraTS (style samples + masks) | Tumor-region segmentation | 50 |

**Note:** Full **LIDC-IDRI** and official **BraTS** archives are very large and need TCIA/challenge access.
This export gives you **50 ready samples per disease path** inside the project for demos, PPT evidence, and testing.

Each folder has `images/`, `labels.csv`, and `README.txt`.
